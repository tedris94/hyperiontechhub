## How to use

1. **Full app in one go**: Paste **01-FULL-PROMPT-HYPERION-EDUSUITE.md** into Figma Make AI for a complete brief (may be heavy; use for structure and reference).
2. **Per module**: Paste **BRAND-COLORS-REFERENCE.md** (or the color table) + **one** module file (e.g. **04-MODULE-STUDENT-MANAGEMENT.md**) for focused, high-quality screens.
3. **Suggested order for generation**:
   - 02 (Auth) → 03 (Dashboards) → 04 (Students) → 07 (Academic) → 08 (Attendance) → 09 (Exams) → 10 (Fees) → then 05, 06, 11–21 as needed.
4. **Consistency**: Start with 02 (Auth) and 03 (Dashboards) to lock layout (sidebar + header); reference that layout in later module prompts if the tool allows.
