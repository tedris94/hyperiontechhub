# Full Figma Make AI Prompt: Leadway College of Advanced Studies Limited

Paste everything below into Figma Make as one prompt.

---

You are designing a premium, production-ready UI/UX for a Nigerian education company: Leadway College of Advanced Studies Limited (formerly Leadway Educational Consults). Product: a responsive web app + marketing site that feels like a top-tier edtech product (Calm x Notion x Stripe Dashboard), not a generic admin template.

PRODUCT GOAL
Unify public marketing, student/parent portals, staff operations, admissions pipeline, exam scheduling & results, and payments (invoices, part-payments, receipts) in one coherent design system. Trust, clarity, and speed for busy parents and administrators.

PRIMARY USERS
1) Prospective student/parent - discover programmes, book consultation, apply online, pay application fee, track status.
2) Enrolled student - timetable, materials, mock exams, results, announcements.
3) Parent/guardian - fees, invoices, payment history, child progress, messages.
4) Tutor/teacher - classes assigned, attendance, grade entry (where applicable), student notes.
5) Registrar / admin - applications, documents, offers, enrolment, cohorts.
6) Finance - fee structures, invoices, reconciliation, refunds workflow.
7) Super admin - roles, audit, settings, branding.

BRAND COLOR DIRECTION (from logo)
- Primary Navy: #0B1E4B
- Secondary Royal Blue: #123C88
- Primary Gold: #C9A24A
- Deep Gold / Bronze: #9D7326
- Light Gold Highlight: #E6CF86
- Off-White/Silver Text: #E8EAF0
- Dark Charcoal Surface: #1A2233

Use navy/charcoal for structure, gold tones for CTA and prestige accents, and off-white for high legibility on dark surfaces.

INFORMATION ARCHITECTURE - DESIGN THESE AREAS (desktop + mobile frames)
A) Marketing site: Home hero (value prop + CTA "Apply" / "Book consultation"), Programmes (IJMB, JAMB, WAEC, NECO + detail pages), Success stories, Fees overview, FAQ, Contact, Footer (trust badges, social, NAP).
B) Auth: Login, register, forgot password, email verification state, optional 2FA for staff.
C) Applicant flow: Multi-step application wizard with progress indicator, document upload with clear requirements, application fee checkout success/failure states.
D) Admissions dashboard (admin): Kanban or table pipeline (Submitted -> Under review -> Interview -> Offer -> Enrolled -> Rejected), applicant profile drawer, internal notes, bulk actions, export.
E) Student dashboard: Next class, assignments/mocks, announcements, quick links, profile completion meter.
F) Parent dashboard: Children switcher, fee balance card, pay now CTA, payment method, receipt download.
G) Programmes & cohorts (admin): Create programme, batch, capacity, timetable builder (weekly grid), assign tutors.
H) Exams: Exam calendar, room/online session details, results table, publish/hide results, student "view result" celebratory but professional empty state.
I) Finance: Invoice list, filters, status tags (Paid / Partial / Overdue), invoice detail, record offline payment, refund request UI.
J) Communication: Notification center, announcement composer (admin), message thread (optional).
K) Settings: Organization profile, academic session, roles & permissions, payment gateway placeholders, email templates list.

VISUAL DIRECTION - BEAUTIFUL & DISTINCTIVE
- Aesthetic: Warm academic modernism - trustworthy, calm, optimistic. Avoid generic templates.
- Typography: Distinctive pairing - refined serif for H1-H3 + highly legible geometric sans for UI/body.
- Layout: Generous whitespace, 12-column desktop grid, consistent 8px spacing rhythm.
- Components: Soft elevation, 1px borders, radius 12-16px, polished tables, clear states.
- Iconography: Thin-line icons with consistent stroke.
- Imagery: Premium education visuals with authentic Nigerian context.

INTERACTION & UX CRAFT
- Primary CTA visible on mobile (sticky where needed).
- Wizard flows with autosave indicator and inline validation.
- Strong table UX: search, filter chips, pagination, bulk actions.
- KPI dashboards with clear priority hierarchy and "Needs attention" cards.
- Subtle motion (150-220ms), not flashy.
- Optional dark mode with maintained contrast and brand accents.

ACCESSIBILITY & LOCALIZATION
- WCAG 2.1 AA contrast minimum.
- Visible focus states and touch targets >=44px.
- Nigerian Naira format (N) and clear date formats.
- Plain language for parent/student-facing experiences.

DELIVERABLES IN FIGMA
- Design system page: colors, type scale, spacing, grids, buttons, form controls, tabs, tags, toasts, modals, cards, table patterns, chart placeholders.
- Core flow prototypes:
  1) Marketing -> Apply -> Pay application fee -> Confirmation
  2) Parent -> View invoice -> Pay -> Receipt
  3) Admin -> Move applicant in pipeline -> Offer
- Desktop templates (1440 width) and mobile templates (390 width) for all major modules.
- Realistic sample data (Nigerian names, plausible programme and fee data).

ANTI-PATTERNS (DO NOT)
- No cluttered dashboards with equal visual weight everywhere.
- No poor contrast or over-styled gradients.
- No inconsistent spacing/radii/colors across screens.
- No generic "template look"; enforce brand personality.

OUTPUT ORDER
Start with:
1) Design system
2) Marketing home
3) Applicant wizard
4) Admissions admin dashboard
5) Parent payment flow

Then expand to remaining IA modules while maintaining full consistency.
